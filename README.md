# chat_arthmil
Este projeto nasceu de uma experiência profissional, na qual desenvolvi um sistema de chat e tive a ideia de adapta-lo para o Ateliê da minha mãe. O objetivo é facilitar a gestão dos atendimentos, centralizar conversas e tornar a comunicação com os clientes mais organizada e eficiente, utilizando a tecnologia para apoiar o negócio da minha família.
